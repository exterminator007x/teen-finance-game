# ภารกิจเศรษฐีวัยรุ่น (Teen Tycoon: Finance Quest) 💰

เว็บเกมจำลองการออมและการลงทุนเพื่อการเรียนรู้ สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 2 ในคาบเรียน 50 นาที

🌐 **ลิงก์เข้าเล่นเกม (Play Game Online):**  
👉 [https://exterminator007x.github.io/teen-finance-game/](https://exterminator007x.github.io/teen-finance-game/)

---

## 🎮 โหมดการเล่น (Game Modes)
1. **📱 โหมดนักเรียน (Student Mode):**
   * นักเรียนเปิดเล่นบนสมาร์ตโฟน แท็บเล็ต หรือเครื่องคอมพิวเตอร์ส่วนตัว
   * จำลองชีวิตวัยเรียน 6 เทอม (ม.1 – ม.3)
   * ตัดสินใจจัดสรรเงินค่าขนมเข้า 3 กระเป๋า:
     * 💵 **เงินสดสำรองฉุกเฉิน (0%):** ป้องกันการติดหนี้ฉุกเฉินเมื่อเจอเหตุการณ์ไม่คาดฝัน
     * 🏦 **เงินฝากธนาคาร/สลาก (+6% ทบต้น):** ปลอดภัย 100% เงินงอกเงยตามเวลา
     * 📈 **การลงทุนวัยรุ่น/หุ้น (-25% ถึง +40%):** ความเสี่ยงสูงเพื่อผลตอบแทนก้าวกระโดด
   * จบเกมรับการวิเคราะห์ **"ฉายาทางการเงิน (Financial Archetypes)"**
2. **👨‍🏫 โหมดคุณครูคุมห้องเรียน (Classroom GM Mode):**
   * ฉายขึ้นจอโปรเจกเตอร์หรือ Smart Board หน้าห้องเรียน
   * แบ่งนักเรียนแข่งขันกัน 2 ถึง 12 กลุ่ม (รองรับห้องเรียนขนาดใหญ่)
   * คุณครูเป็นผู้คุมเวลา สุ่มการ์ดเหตุการณ์ชีวิตและการ์ดตลาดเศรษฐกิจให้ทั้งห้องลุ้นร่วมกัน
   * ตารางจัดอันดับสด (Leaderboard) และพิธีมอบรางวัลจบ ม.3
